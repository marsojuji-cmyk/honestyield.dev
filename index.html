The Honest-Yield Rule

Honest yield means one thing: yield you can prove. Any claim that a system saves tokens, money, or time must cite an admitted run pair. Without one, the number is null.

  1. 1

    A yield claim is a measured claim. Any statement that a system saves tokens, money, or time must cite an admitted run pair.

  2. 2

    A run pair is a before-and-after measurement on the same workload under stated conditions: inputs, model, configuration, date.

  3. 3

    Without an admitted run pair, the savings number is null. No pair, no number.

  4. 4

    Negative results are admitted. A run pair showing no measurable gain is a valid ledger entry — and often the most informative one.

  5. 5

    The ledger is append-only. Corrections are new entries; nothing is rewritten.

  6. 6

    Authority only narrows. A grant of authority can be reduced, never silently expanded.
